## Overview

A channel dashboard built around a football live-stream YouTube channel: channel-level analytics, a live match view, a video library, and viewer comments — the kind of internal tool a channel operator would actually use day to day.

## Build

- **Channel Overview** — subscribers, total views, live viewer count, watch time, and videos published, plus a views-by-category chart; several stats are computed live from the underlying video/comment data rather than hardcoded
- **Live Stream** — a YouTube embed slot that falls back to a broadcast-style placeholder (not a random video) with live score, match stats, and an event feed
- **Videos** — a paginated video library with category badges and view/duration metadata
- **Comments** — YouTube-style viewer comments with likes and relative timestamps
- Full light/dark theme across the whole app, including a dedicated always-dark token for video/thumbnail surfaces so they never turn white in light mode

## Tech Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui · Recharts · Material UI
