## Overview

Developer Hub is a dashboard-style app for keeping the tools, docs, snippets, and links a developer reaches for every day in one organized interface.

## Build

- Full workspace sidebar — Dashboard, Projects, Documentation, Snippets, API Explorer, Tools, Bookmarks, Settings — each with real content
- Resizable panel layout for the sidebar and content area
- Full light/dark theme via next-themes, including a dedicated theme toggle
- Component-based architecture — every dashboard section is its own component backed by typed mock data
- Charts on the dashboard overview via Recharts

## Tech Stack

Next.js · TypeScript · Tailwind CSS v4 · shadcn/ui · Recharts · next-themes · Lucide Icons
