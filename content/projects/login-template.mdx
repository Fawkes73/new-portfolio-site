## Overview

A split-screen sign-in template: a decorative gradient/dot-grid showcase panel on one side, a real sign-in form on the other — built to drop into any project without needing stock photography.

## Build

- Split-screen layout that collapses to a single column on mobile
- Real sign-in form: email/password with a show/hide password toggle, "Forgot password?" and "Sign up" links
- Full light/dark theme via next-themes — including the gradient panel, not just the form
- Local shadcn/ui components, no external UI dependency beyond Radix primitives
- Showcase panel is a CSS gradient mesh + dot grid — nothing to license or swap out

## Tech Stack

Next.js · TypeScript · Tailwind CSS v4 · shadcn/ui
