## AI-Assisted Development

I use AI as a development accelerator across my workflow — not as a replacement for engineering judgment.

I use AI tools to:

- Rapidly prototype ideas
- Generate initial implementations
- Explore unfamiliar APIs and frameworks
- Refactor and improve existing code
- Debug errors and investigate issues
- Generate boilerplate and repetitive code
- Explore alternative architectural approaches
- Create tests and development utilities
- Iterate quickly on UI and functionality
- Accelerate game development and asset workflows

My workflow is essentially:

**Idea → Prompt → Generate → Review → Understand → Test → Modify → Ship**

I don't treat generated code as automatically correct. I review the implementation, understand the architecture, test the behavior, debug issues, and adapt the code to the actual requirements of the product.

I started with the fundamentals—**C, C++, programming logic, data structures, and algorithms**—and gradually moved through different layers of software development: Java and .NET, databases, web development, mobile applications, blockchain, game development, SaaS, and algorithmic systems.
